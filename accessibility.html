Accessibility statement

Our commitment to making this website usable by as many people as reasonably possible.

Last reviewed: 17 July 2026

CommitmentSupported featuresKnown limitationsFeedback

1. Our commitment

Systems and Scale Group Ltd wants this website to be accessible to the widest practical audience, including people who use assistive technologies. We aim to follow the principles of the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA where reasonably possible.

2. Accessibility features

The website includes:

  • semantic headings and landmarks to support screen-reader navigation;
  • keyboard-accessible navigation and controls;
  • a visible skip link;
  • clear focus states and sufficient colour contrast;
  • responsive layouts that avoid horizontal page scrolling on common mobile widths;
  • text alternatives for meaningful images;
  • support for reduced-motion preferences.

3. Known limitations

Some decorative motion and complex visual layouts may be less helpful to certain users, although reduced-motion settings are respected. Externally hosted font files may be unavailable in restrictive network environments; the site falls back to standard system fonts.

4. Using this website

You can zoom text and page content using your browser. The layout is designed to reflow at smaller widths. Navigation, cookie choices and links can be operated using a keyboard.

5. Feedback and contact

If you find an accessibility problem or need information in another format, email accessibility@systemsandscale.co.uk. Please include the page address and a brief description of the issue. We aim to acknowledge accessibility feedback within five working days.

6. Review

We review this statement and the website periodically as content, technology and accessibility guidance evolve.
